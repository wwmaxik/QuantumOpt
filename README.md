# 🚀 QuantumOpt (Balatro FPS & Instant Scoring Optimizer with Native Rust Core)

> [!NOTE]
> **Статус: Публичная Бета (v1.4.0-beta)**  
> Мод сейчас находится в стадии активного бета-тестирования. Если вы обнаружите баг или странное поведение, создайте Issue!

Высокопроизводительный мод оптимизации для **Balatro** (Steamodded / Lovely), разработанный специально для тяжелых бесконечных забегов (Endless Runs, Ante 30+) со 150+ джокерами, 100+ расходниками и астрономическими числами (**Cryptid**, **Talisman**, **Amulet**).

Содержит нативный скомпилированный движок на **Rust** (`libquantum_core.so`), подключаемый через **LuaJIT FFI** без накладных расходов.

---

## ⚡ Что оптимизирует QuantumOpt v1.4.0-beta?

1. **⚡ Мгновенный подсчет очков (Instant Scoring & Calculation Acceleration):**
   * **Устранение $O(N^2)$ цикла `other_joker`:** при 150+ джокерах vanilla/SMODS на каждый триггер перебирал всех остальных джокеров (`150 * 150 = 22,500` вызовов на карту). QuantumOpt проверяет байткод джокеров и мгновенно отсекает 99% ненужных вызовов, экономя сотни тысяч операций за руку.
   * **Автоускорение Talisman / Amulet:** автоматически переключает `disable_anims = true` и поднимает `coroutine.framecalc` с 250 до 100,000. Игра больше не делит вычисление очков на 400 медленных кадров, счет завершается мгновенно.
   * **Сжатие задержек очереди событий:** срезает искусственные паузы `delay(0.6-0.8s)` и вызовы `card_eval_status_text` во время розыгрыша руки до 0.001 секунды.
   * **Турбо-дрейн EventManager:** очередь событий сбрасывается пачками по 20 событий за кадр, устраняя зависание розыгрыша на минуты.

2. **🦀 Нативный Rust Core (`libquantum_core.so`):**
   * **SIMD-кинематика перемещения карт:** вычисление физики и лерпа для сотен объектов `MOVEABLES` перенесено в Rust, исполняется за микросекунды с векторными инструкциями CPU.
   * **Fast Collisions:** сверхбыстрое определение пересечений точки с повернутыми прямоугольниками карт на Rust.

3. **Ликвидация смертельного цикла nuGC (главная причина 1-3 FPS):**
   * В ванильном коде Balatro при превышении 300 МБ памяти каждый кадр вызывался принудительный полный проход сборщика мусора `collectgarbage("collect")`.
   * При модах вроде Cryptid/BigNum память стабильно держится на 400-800 МБ, вызывая заморозку каждого кадра на 100-300 мс.
   * `QuantumOpt` перехватывает `nuGC`, предотвращает полные стоп-кадры и настраивает инкрементальную, плавную сборку мусора.

4. **Кэширование коллизий курсора (`Controller:get_cursor_collision`):**
   * Предотвращает бессмысленный перебор 2000-4000 элементов отрисовки каждый кадр, если мышь находится в покое.

5. **Устранение $O(N^2)$ циклов в пассивных джокерах:**
   * В забегах со 150 джокерами ванильные проверки карт (Temperance, Stencil, Driver's License) создавали до 25,000 проверок за кадр (60 раз в секунду). Данные пересчеты кэшируются.

6. **Culling и Thin-Draw для перекрытых карт:**
   * Срез лишних слоев, теней и тяжелых шейдеров для неактивных карт в больших стеках (>16 карт).

7. **Диагностический оверлей с индикатором Rust:**
   * Аккуратный счетчик FPS в реальном времени с выводом нагрузки `Upd (CPU)`, `Ev (Events)`, `Drw (GPU)`, RAM и статусом `Rust:ON`.

## 📥 Установка

### Вариант 1: Через Balatro Launcher
Мод доступен напрямую во встроенном каталоге **[Balatro Launcher](https://github.com/wwmaxik/balatro-launcher)** во вкладке «Утилиты & QoL». Нажмите **«Установить»**!

### Вариант 2: Вручную
1. Убедитесь, что установлены **Steamodded (smods)** и **Lovely**.
2. Скачайте репозиторий:
   ```bash
   cd ~/.local/share/balatro/Mods
   git clone https://github.com/wwmaxik/QuantumOpt.git
   ```
3. Запустите Balatro! Нативная библиотека `libquantum_core.so` уже скомпилирована и подхватится автоматически.

---

## 🛠️ Сборка Rust Core из исходников (опционально)
Если вы хотите пересобрать `libquantum_core.so` самостоятельно:
```bash
cd QuantumOpt/native
cargo build --release
cp target/release/libquantum_core.so ../
```
